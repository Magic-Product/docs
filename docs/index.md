# Сеть маникюрных салонов

Микросервисная система управления сетью салонов.

## Сервисы

- **Gateway** — единая точка входа
- **Catalog** — услуги и филиалы
- **Staff** — мастера и расписания
- **Customer** — профили клиентов
- **Booking** — записи и слоты
- **Finance** — выручка и зарплаты
